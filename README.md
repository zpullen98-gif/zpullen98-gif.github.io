**Open the app: https://zpullen98-gif.github.io/**

The complete life of the hospitality professional, in one app. Free, no account, and it

It installs as a single app with one icon, and all five wings live inside it.

## Installing it

**On an iPhone or iPad.** Open the link in **Safari**. It has to be Safari: a link tapped
inside Messages or Instagram opens in that app's own browser, which has no install
option at all. Tap the Share button, the square with the arrow coming out of it, scroll
down, and choose *Add to Home Screen*.

**On an Android phone.** Open the link in Chrome, open the three-dot menu, and choose
*Install app*. Chrome often offers it in a banner without being asked.

**On a computer.** Open the link in Chrome or Edge and click the install icon at the
right-hand end of the address bar, a small monitor with a downward arrow. If it is not
showing, the three-dot menu has *Install page as app*. Safari on a Mac puts it under
File, *Add to Dock*.

Installing from any page installs the whole product. Somebody who installs while reading
a recipe gets Outside Of Time Hospitality, not a World Table that happens to be open.

## Using it with no signal

Opening a wing stores that wing as you read it, so the app fills in offline as it gets
used. To get everything at once there is a button on the home page, under *Free, all of
it*: **Make every wing available offline**. It is about 50 MB and is worth doing on wi-fi
before a trip.

## Your work stays yours

Every journal entry, quiz score, streak and note lives in the browser on the device it
was written on. Nothing is uploaded, there is no account, and there is no server holding
anyone's records. Sharing the link shares the app, never your work.

If two people share a device, each can tap *Add your name* on a wing's home page and keep
a separate record from then on.
